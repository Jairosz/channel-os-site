Política de privacidad de Channel OS Control Panel

Última actualización: 27 de octubre de 2026

1. Qué es Channel OS

Channel OS Control Panel (en adelante, "la aplicación") es una aplicación privada, de uso exclusivo de su propietario, para gestionar sus propios canales de YouTube. No está abierta al público y no recoge datos de otros usuarios.

2. Datos de Google a los que accede

Mediante el inicio de sesión con Google (OAuth 2.0) y los permisos de la API de YouTube, la aplicación accede únicamente a los canales del propietario para:

  • subir vídeos y programar su publicación;
  • editar título, descripción, miniatura y metadatos de esos vídeos;
  • leer estadísticas y analíticas de los propios canales (YouTube Analytics API).

No se accede a datos de otros canales ni de otros usuarios, ni a contactos, correo o archivos.

3. Cómo se almacenan y protegen los datos

Los tokens de acceso de Google se guardan cifrados (AES-256-GCM) en una base de datos privada controlada por el propietario. Las estadísticas descargadas se almacenan en esa misma base de datos con el único fin de mostrar informes al propietario.

4. Compartición de datos

Ningún dato obtenido de Google se vende, cede ni comparte con terceros. Los datos solo se transmiten a los servicios de Google necesarios para las funciones descritas.

5. Uso de la información de las API de Google

El uso y la transferencia de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

6. Conservación y eliminación

El propietario puede revocar el acceso en cualquier momento desde la configuración de permisos de su cuenta de Google o desconectando el canal dentro de la aplicación, lo que elimina los tokens almacenados.
